InkPointX XTEINK X4 Pro — обязательный протокол первого полевого теста
=====================================================================

СТАТУС
------
Это экспериментальная app-only прошивка. Она не является подтверждённым на
конкретном физическом устройстве релизом. Не используйте другие прошивальщики,
не запускайте erase-flash/erase-all и никогда не добавляйте --force.

Пакет не содержит bootloader, partition table, NVS или factory image. Заводской
app1 остаётся во flash. Автоматический rollback OEM bootloader не подтверждён;
восстановление выполняется через ROM download mode командой restore-stock.
Тестовая прошивка не сохраняет подсветку, Wi-Fi или PHY-калибровку в OEM NVS:
это намеренное ограничение ради сохранности заводских данных. Встроенный guard
отклоняет записи/стирания любых flash-разделов, кроме служебного otadata.

ПОДГОТОВКА
----------
1. Зарядите устройство минимум до 50%. Используйте исправный короткий USB-кабель
   и прямой порт компьютера без USB-хаба. Не допускайте отключения питания.
2. Установите инструменты:
   python3 -m pip install --upgrade "esptool>=5.3,<5.4"
3. Проверьте версию:
   esptool version
   espefuse --help
4. Войдите в ESP32-S3 ROM download mode, удерживая кнопку GPIO0 во время reset/
   включения. Подставьте реальный порт вместо /dev/ttyACM0.

ШАГ 1 — ПОЛНЫЙ BACKUP 16 МБ
---------------------------
python3 x4pro_safe_flash.py backup \
  --port /dev/ttyACM0 \
  --output x4pro-backup

Если появился SAFETY STOP, не продолжайте и сохраните весь вывод терминала.

ШАГ 2 — НЕЗАВИСИМАЯ ПРОВЕРКА
----------------------------
Физически отключите USB, снова войдите в ROM download mode и выполните:

python3 x4pro_safe_flash.py verify \
  --port /dev/ttyACM0 \
  --backup x4pro-backup

ШАГ 3 — УСТАНОВКА В НЕАКТИВНЫЙ APP0
-----------------------------------
Возьмите хеш InkPointX-X4Pro.bin из SHA256SUMS и выполните:

python3 x4pro_safe_flash.py install \
  --port /dev/ttyACM0 \
  --backup x4pro-backup \
  --firmware InkPointX-X4Pro.bin \
  --firmware-sha256 ВСТАВЬТЕ_64_СИМВОЛА_SHA256 \
  --confirm PRESERVE-FACTORY-APP1

Установщик до записи проверяет MCU, MAC, flash 16 МБ, Secure Boot, flash
encryption, SECURE_VERSION, OEM-разметку, полный factory app1 и внутреннюю
целостность бинарника. Затем он записывает app0, проверяет его чтением, и только
после этого записывает один неактивный 4-КБ сектор otadata.

После сообщения INSTALL VERIFIED вручную перезагрузите устройство обычным
способом. Сохраните полный serial log 115200 baud. Первые 60 секунд не отключайте
питание. Если дисплей не обновился, не повторяйте установку: снимите serial log и
выполните восстановление ниже.

ВОССТАНОВЛЕНИЕ FACTORY APP1
---------------------------
Снова войдите в ROM download mode:

python3 x4pro_safe_flash.py restore-stock \
  --port /dev/ttyACM0 \
  --backup x4pro-backup \
  --confirm RESTORE-FACTORY-BOOT

Команда повторно проверяет MCU, MAC, security eFuses, bootloader/partition/NVS и
полный factory app1. Для выбора app1 она пишет только один неактивный сектор
otadata. При потере питания второй, ранее активный сектор остаётся загрузочным.

Не удаляйте x4pro-backup. Он содержит уникальный NVS конкретного устройства и
не должен передаваться владельцу другого X4 Pro.
