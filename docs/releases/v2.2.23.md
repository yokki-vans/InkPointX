## What's new

- A calmer, polished end-of-book screen with the finished book's cover and up to three next-book suggestions.
- Larger recommendation covers, real cached covers when available, and consistent placeholders when a book has no cover.
- Fixed completed books getting stuck at `100%` but one page short, such as `752 / 753`.
- Existing completed-book records are repaired automatically in the Home summary.
- Final EPUB progress is now saved before opening the end-of-book screen.

The firmware image is universal for XTEINK X3 and X4; the device model and display backend are selected automatically at boot.
