## InkPoint X v2.3.4

Recovery release from the last known-good `dev` baseline, v2.2.28.

The v2.3.0–v2.3.3 releases are withdrawn after field reports of regressions.
This build restores the v2.2.28 firmware behavior for XTEINK X3 and X4 while
using a newer version number so affected devices can recover through OTA.

- Restores the v2.2.28 display, navigation, input, wake and sleep paths.
- Temporarily removes the v2.3 dark-mode implementation and the unverified X3
  refresh/input candidate. They will return only after separate validation.
- Keeps books, reading progress and existing settings on the microSD card. The
  retired `darkMode` JSON key is safely ignored by this version.
- Correctly records `v2.3.4` in the ESP application descriptor.
- Makes `dev` the enforced release source. Tags from `main` or unmerged feature
  branches are rejected before a firmware build can be published; the embedded
  version is verified before release assets are uploaded.

Users running v2.3.0–v2.3.3 should install this update. `firmware.bin`,
`update.bin` and the X3/X4-labelled downloads contain the same universal
ESP32-C3 firmware; checksums are in `SHA256SUMS`.

The runtime behavior matches the previously published v2.2.28 baseline; code
changes are limited to the version/application descriptor and release checks.
No physical device was connected for this recovery build, so the release does
not claim new hardware validation beyond that known-good baseline.
